# بيتك في ايدك — Turath Code

منصة مصرية لعرض وتأجير **المباني والشقق المعطلة** (موجودة ومفيهاش ساكن). Laravel 11 + MySQL، واجهة عربية RTL بنفس تصميم مشروع Palmenburg (Alexandria + كحلي + وضع ليلي + Dock).

## الأدوار
- **المالك**: يضيف عقاره بالصور والعنوان بالتفصيل، مرحلة التشطيب (هيكل / طوب / محارة / نصف تشطيب...)، جدول بنود التشطيب (متوفر / جزئي / ناقص)، سعر السوق والإيجار المعروض ومدة الإيجار (min/max)، فترة سماح وزيادة سنوية.
- **المستأجر**: حساب ببياناته (اسم، تليفون، إيميل، صورة)، الحالة الاجتماعية والغرض من الشقة، مفضلة ومقارنة وداشبورد، تقديم عرض (إيجار + مدة) والتفاوض.
- **الأدمن (صاحب المنصة)**: يراجع العقارات ويعتمدها، يدير المستخدمين والطلبات والإعدادات، ويتابع نسبته.

## ضمان حق المنصة
- نسبة المنصة من كل طرف (افتراضي 5% للمالك + 5% للمستأجر) تتغير من الإعدادات، وتتثبت على الطلب لحظة الاتفاق.
- بيانات التواصل (تليفون/إيميل/واتساب) **مخفية** وأي رقم في الرسائل بيتمسح تلقائيًا.
- لا تظهر البيانات ولا يتحوّل العقار إلى "مؤجر" إلا بعد ما الأدمن يسجّل سداد نسبة **الطرفين**.

## التشغيل
```bash
composer install
cp .env.example .env        # عدّل بيانات MySQL
php artisan key:generate
php artisan migrate --seed
php artisan storage:link
php artisan serve
```
حساب الأدمن الافتراضي: `admin@turathcode.com` / `Admin@12345` — **غيّره قبل النشر**.
في بيئة `local` بيتضاف مالك ومستأجر وعقارات تجريبية (`owner@example.com` / `tenant@example.com`، كلمة المرور `password`).
